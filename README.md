# 📝 StickyNote (Linux)

StickyNote is a simple tool that runs on Linux systems for writing quick notes using Python and the `tkinter` GUI library.

---

## 🐧 This program is designed specifically for Linux users.

---

## 📦 Requirements
1- pip 
2- python3

#### ➤ On Ubuntu / Debian:
====> bash
sudo apt update
sudo apt install python3-tk
### على Arch / Manjaro:

sudo pacman -S tk

=> To Run the App:
python3 stickynote.py
